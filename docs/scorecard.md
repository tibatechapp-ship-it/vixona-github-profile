## 3) بطاقة كل مشروع من النواة الخمسة (الدليل التفصيلي)

### 1. nexus-core — 8.4/10
- **ما هو**: نظام وكلاء AI موحّد — ذاكرة طويلة المدى، تعلّم أدوات، مجلس قرارات (council)، وكيل رئيسي + وكيلات متخصصة.
- **أدلة التنفيذ** (تشغيل فعلي 2026-11-01): **3,943 passed/28 skipped في 212 ملفاً** (coverage 98.13%) · CI + Tests + قياسات خضراء على main · 117K سطراً · توثيق حوكمة نادر: SCOPE/VISION_2026/ADVERSARIAL/LESSONS · Docker · **أسبوع 1**: `/dashboard` + `/api/dashboard` (8 اختبارات) · **أسبوع 2**: trace logs معيارية — `src/observability/trace.py` (خيط-آمن، تدوير 5MiB، بلا PII) + 20 اختبار انحدار + `/api/trace/recent` · **أسبوع 3**: قياسات آلية — 20 مهمة معيارية على EchoBackend + **بوابة انحدار p50 (>50% وفارق >0.2ms يسقط البناء)** + `docs/benchmarks.md` ذاتي التحديث (وضع تأسيس حتى اعتماد خط الأساس على runner حقيقي).
- **أكبر خطرين على الجاهزية**: لا يوجد demo مستضاف يجرّبه الغريب في 60 ثانية؛ خط الأساس القياسي غير معتمد بعد (وضع تأسيس).
- **الفجوة الوحيدة**: demo مستضاف + `--adopt` لخط الأساس بعد جولة على runner مستقر.

### 2. Rasan — رسن — 8.5/10
- **ما هو**: دردشة جماعية E2EE بلا رقم هاتف، عربية RTL أولاً — PWA اليوم، ومتاجر غداً.
- **أدلة التنفيذ** (تشغيل فعلي 2026-11-01): **478 اختبار زمني أخضر** (415 خادم vitest في 27 ملفاً تشغيل فعلي + 47 جوال CI + 16 وحدة ويب `node --test`) + E2E Playwright 3/3 رحلة زائر كاملة · **أسبوع 2**: صفحة التجربة العامة + E2E حقيقي بخادم وقاعدة مؤقتة وChromium (workflow مستقل) · **أسبوع 3**: بنية MLS للمجموعات بروح RFC 9420 (إبوكات + أغلفة إفيمرالية P-256 + commitment + أي-عضو-يصدر-commit) — 22 اختباراً + إصدار v1.1.0 · قائمة فحص ميداني 25 بنداً على أجهزة حقيقية بحرس CI (لا نتائج مصطنعة) · **تقدّم إضافي (أسبوع 4 انطلق فعلاً)**: جلسات مرئية بنمط Signal + تصدير محادثة مشفّر ذاتياً — v1.2.0 بـ409 اختباراً قبل أن تُدمج قائمة الفحص فوقها (415).
- **أكبر خطرين على الجاهزية**: تنفيذ قائمة الفحص الميداني فعلياً على أجهزة حقيقية (القائمة جاهزة والنتائج تُسجل عند التنفيذ)؛ توقيع المتجر الحقيقي (keystore كـsecret).
- **الفجوة الوحيدة**: تنفيذ الفحص الميداني + نشر المتاجر.

### 3. lifelink-app — 7.9/10
- **ما هو**: شبكة إنقاذ وتبرع بالدم بخصوصية مصممة من السطر الأول (PII-minimal).
- **أدلة التنفيذ**: **98/98 pytest** (CI أخضر) · أمان ملموس: JWT، تحديد معدل، ترحيلات idempotent تُثبت على Postgres حقيقي في CI · Docker · إصدار v1.0.0 · لقطات حقيقية · **أسبوع 1**: مطابقة جغرافية haversine بـ16 اختباراً + ترحيل بذهاب-وعودة مثبت · **أسبوع 2**: حزمة ثقة المشغّل `docs/trust/` (سياسة بيانات بـ«ما لا نجمعه»، احتفاظ وحذف، DPIA مبسطة، مسؤوليات) + `/admin/stats` بصلاحيات مُختبَرة (401/403/200) وزمن استجابة صادق عبر ترحيل fulfilled_at — 12 اختباراً جديداً.
- **أكبر خطرين على الجاهزية**: لا شريك أول (بنك دم/مبادرة) يجرب فعلياً بعد؛ الأحمال الحقيقية (حجم المتبرعين) غير مُختبَرة.
- **الفجوة الوحيدة**: شريك تشغيل أول.

### 4. nexhub — 7.2/10
- **ما هو**: مساحة عمل مطوّر عربية تعمل offline — Git محلي، بلا حساب، بلا سحابة.
- **أدلة التنفيذ**: 45/45 اختبار + `flutter analyze` صفر · CI + Build + docs أخضران · نشر Pages · **أسبوع 1**: جولة onboarding 5 خطوات · **أسبوع 2**: quickstart مصوّر `docs/quickstart-ar.md` بمخطط SVG عربي + حرس وثائق في CI (وجود/صور/روابط) + وظيفة release ترفق APK×3 وحزم سطح المكتب آلياً — **Release v1.1.0 بـ6 أصول موثقة**.
- **أكبر خطرين على الجاهزية**: لا مستخدمون مبكرون بعد؛ محتوى المجتمع (قوالب/أمثلة) رقيق.
- **الفجوة الوحيدة**: مستخدمون أوّلون + محتوى مجتمعي.

### 5. BASIRAH-AI — بصيرة — 7.4/10
- **ما هو**: ذكاء وثائق عربية — OCR + embeddings (pgvector) + استخراج كيانات، في Docker stack جاهز.
- **أدلة التنفيذ** (تشغيل فعلي 2026-11-01): **66/66 pytest** (كانت 29 مجمّعة فقط) · CI أخضر بشقّه (test + conda) · مقياس ذهبي Recall@5=0.975/MRR=0.975 ببوابة CI تفشل تحت 0.70/0.50 · **أسبوع 2**: لوحة وصفية `/dashboard` + بحث تفاعلي صادق التسمية بـ10 اختبارات · **أسبوع 3**: chunking عربي مضبوط بدليل حتمي — Recall@5 على وثائق مركّبة **0.400 → 0.575 (+0.175)** بلا أي انحدار على مقياس CI (0.975 ثابت) وMRR بلا مكسب (موثق بصدق في `docs/chunking-tuning.md` ومثبّت بـ3 اختبارات) · بحث على مستوى الأقسام + `snippet` من القسم المطابق · **إصدار v0.5.0 تلقائي** بوظيفة CI على وسم v* بمرفق أدلة JSON.
- **أكبر خطرين على الجاهزية**: قياس chunking بالنموذج الحقيقي (MiniLM) على PostgreSQL لم يتم بعد — الدليل الحالي بتضمينات hashing حتمية توضح الآلية؛ أرشيف حقيقي طويل لم يُجرّب.
- **الفجوة الوحيدة**: أرشيف شريك حقيقي + قياس النموذج الفعلي على Postgres.

## 5) ما الذي تغيّر عن التقييم الخارجي؟ (تصحيحات صادقة)

1. **Rasan أعلى من التقييم المحيطي**: التقييم الخارجي رصد «غياب المصادقة/المجموعات/الإشعارات/المشاركة/الإشراف» — هذه **موجودة كلها ومُختبَرة** (JWT + تخزين آمن + 401 مركزي، مجموعات 50K + قصص، FCM، مرفقات E2EE + بحث، إشراف كامل). من ذلك اليوم أيضاً: demo عام + E2E + MLS — لذلك الجاهزية 7.5 لا أقل (لم تصل 8.5 المتوقعة خطةً لأن الفحص الميداني 25 بنداً لم يُنفذ فعلياً على أجهزة حقيقية بعد — القائمة جاهزة بحرس CI).
2. **nexhub أعلى تنفيذاً وسرداً أضعف**: المشكلة ليست الكود (analyze صفر، 45/45) بل الهوية والسرد — أُصُحّب الهوية بدل إنقاص التنفيذ.
3. **qubhub ليس «local AI»**: هو خادم إحصاءات يحترم الخصوصية — مكوّن منظومة، وُضّح في مكانه الصحيح (5.3).
4. **olmo ليس مشروعاً قائماً**: أُدمج في NexHub — يقيَّم كبقايا دمج (4.3) لا كمشروع مستقل.
5. **المحفظة الفعلية 10-11 مشاريع لا 17**: ثلاثة مؤرشفة (NexunGu، novasphere، tyb-zyv-ai) وثلاثة مُمتصّة (wifi-chat→رسن، NexunGu→qubhub، tyb-zyv-ai→nexus-core) وfork مرجعي.
6. **tayf انضم اليوم (11/11)**: CI كان يفشل في 3 ثوانٍ بلا خطوات — التشخيص: جدار فوترة Actions على مستودع خاص («recent account payments have failed or your spending limit needs to be increased»)، لا عيب في الكود (موثق في TASK_TRACKER.md للمشروع). الحل: جعل المستودع عاماً + LICENSE MIT بمعيار المحفظة → CI أخضر (66/66 pytest + بناء tsc نظيف). درجاته صادقة لمرحلته المبكرة: جاهزية 3.5 (لا auth، لا توليد فيديو بعد، مرحلة 3 من 12).

## 6) إعادة إنتاج الأدلة

```bash
# Rasan — خادم وويب وجوال
cd Rasan && npx vitest run                # 415/415 (27 ملفاً)
npm run verify                            # + lint + وحدات الويب 16/16
cd mobile && flutter test                 # 47/47
# lifelink-app
python -m pytest -q                       # 98/98
# nexhub
flutter gen-l10n && dart run build_runner build --delete-conflicting-outputs && flutter test  # 45/45
# tayf
cd tayf/backend && python -m pytest -q    # 66/66
cd ../frontend && npm ci && npm run build # tsc نظيف + bundle
# BASIRAH-AI — مقياس الجودة + أدلة الضبط الحتمية + الاختبارات
cd BASIRAH-AI
PYTHONPATH=src python src/api/eval_retrieval.py --corpus tests/eval/corpus.json --golden tests/eval/golden_set.json  # Recall@5=0.975, MRR=0.975
python scripts/tune_chunking.py           # R@5 المركّبة: 0.400 (بلا) → 0.575 (400/1) — لا انحدار 0.975
python -m pytest -q                       # 66 passed/1 skipped
# nexus-core
NEXUS_ALLOW_OPEN=1 python -m pytest -q    # 3,943 passed/28 skipped (212 ملفاً)
NEXUS_ALLOW_OPEN=1 python scripts/benchmarks/run_benchmarks.py --check  # 20 مهمة + بوابة p50
# حالة CI
gh run list -R tibatechapp-ship-it/<repo> -b main --limit 3
```
